# Security

Please report vulnerabilities privately, not in public issues: use GitHub's
"Report a vulnerability" (Security tab, then Advisories) on this repository.

We acknowledge reports within three working days, keep you informed while
we fix the issue, and credit you in the release notes unless you'd rather we
didn't.

Supported: the latest release.

The SDK masks secrets and personal data on the device before anything is
sent, with the same rules as the Fixwire server. A way to get something past
that masking is a vulnerability too.
